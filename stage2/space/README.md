# ИУС обработки обращений в службу технической поддержки

Учебный сервис этапа 2 практического задания по дисциплине «Проектирование информационно-управляющих систем» (МИЭМ НИУ ВШЭ, вариант 12): портал клиента, рабочее место инженера с ИИ-ассистентом, контроль SLA с журналом уведомлений, отчёты и KPI.

Вход — по личным логинам. Исходный код, документация и отчёт: https://github.com/plisssa/ius-stp

Учебные обращения основаны на наборе Customer Support Tickets (Tobi Bueck, CC BY-NC 4.0), переведённом на русский язык.
