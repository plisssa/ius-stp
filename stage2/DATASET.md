# Учебная выборка ИТ-обращений

Автор внешнего набора — Tobi Bueck. Источник — [Customer Support Tickets](https://huggingface.co/datasets/Tobi-Bueck/customer-support-tickets). Оригинал синтетический, на английском языке. Для учебного стенда заголовки и тексты 240 обращений переведены на русский локальной моделью Argos Translate en→ru 1.9. Часть заголовков отредактирована вручную. Поля row и source_hash связывают перевод с оригинальной записью и позволяют проверить её при повторном импорте. Лицензия [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) допускает некоммерческое использование с указанием авторства и условий. Эти условия распространяются на импортированную часть data.json.

Файл dataset-tickets-multi-lang-4-20k.csv, ревизия ddf1c81a5475992c4fa6752bf1e8b4e31f07bbeb. Поле row указывает номер записи CSV с учётом заголовка (счёт с двух). Отобраны обращения Technical Support и IT Support с разными заголовками. Приоритеты преобразованы в P2–P4, темы назначены по словам в заголовке. Номера ES, организация, сроки и статьи первичной диагностики добавлены проектом. Ответы из источника в модель не передаются. Темы эвристические и требуют независимой разметки для оценки качества ассистента.

Три русскоязычных обращения сохранены как контрольные примеры. Адресованные клиенту вопросы составлены на русском для учебной демонстрации. Редактор, статьи и ответы инженера используют русский язык.

Для воспроизведения [скачайте CSV указанной ревизии](https://huggingface.co/datasets/Tobi-Bueck/customer-support-tickets/resolve/ddf1c81a5475992c4fa6752bf1e8b4e31f07bbeb/dataset-tickets-multi-lang-4-20k.csv) и передайте его путь в import_dataset.py.
