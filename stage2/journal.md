По сообщению команды, преподаватель проверил этап 1 без замечаний. В стендовой сессии роль «Инженер Демо» используется для воспроизводимого сценария.

Повторная проверка 22.11.2026 охватила загрузку 240 синтетических англоязычных обращений с четырьмя темами, поиск, пустую выдачу, черновики при переключении, отправку правок, фильтр статуса и ширину экрана 390 px. Проверка verify_team.py с двумя логинами подтвердила общую базу, персональный аудит и отказ в повторном ответе. Обе внешние проверки Cloudflare вернули HTTP 530: HTTP/2 не завершил TLS-соединение, QUIC не дождался пакетов от региона. Локальная работа и проверка персонального входа прошли.

Резервный HTTPS-сервер запущен на частном адресе Mac. Запрос без логина получил 401; запросы с персональными логинами двух коллег — 200 с правильным именем. TLS проверен по сертификату стенда. Проверка выполнена с хоста через его сетевой IP. Устройства коллег в тесте не участвовали. Попытка localhost.run завершилась до получения проверяемого ключа SSH.

Русская очередь: локально переведены заголовки и тексты 240 заявок. Повторный импорт из исходного CSV сохранил контрольную сумму data.json. Проверены реальный вызов модели, отказ TCP и восстановление соединения в одном сеансе Chrome. Поле ручного ответа сохраняет текст при ошибке. Для ознакомления из интернета добавлен режим GitHub Pages, где ответы хранятся в текущей вкладке.
