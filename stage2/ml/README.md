# Классификатор обращений (предложения А1 и А2)

Модель предлагает инженеру **тип обращения** (А1) и **приоритет по описанию** (А2). Предложение видно на карточке заявки; тип меняется только после решения инженера, приоритет — подсказка для запроса обоснования у клиента (BR-14). Черновик первого ответа (А4) готовит языковая модель, см. [../README.md](../README.md).

| Файл | Назначение |
|---|---|
| `model.json` | Словарь, веса idf и коэффициенты логистической регрессии для двух задач |
| `metrics.json` | Метрики на отложенной выборке, матрицы ошибок, проверка на демонстрационных заявках стенда |
| `train.py` | Обучение (scikit-learn): TF-IDF по словам и парам слов, логистическая регрессия с балансировкой классов |
| `translate.py` | Перевод обучающих обращений en→ru моделью Argos Translate 1.9 через CTranslate2 |
| `../classifier.py` | Применение модели в сервисе без внешних библиотек; совпадение с scikit-learn проверяется при обучении |

## Данные и разметка

Источник — синтетический набор Customer Support Tickets (Tobi Bueck, CC BY-NC 4.0, ревизия из [../DATASET.md](../DATASET.md)). Взяты англоязычные обращения очередей Technical Support, Product Support, IT Support и Service Outages and Maintenance; 243 заявки стенда в обучение не входят. Тема и первые 400 знаков текста переведены на русский язык.

Метки набора сопоставлены справочникам кейса (допущение, ASM-11):

| Набор данных | Кейс |
|---|---|
| Incident, Problem | Ошибка |
| Request | Вопрос по функционалу |
| Change | Вопрос по конфигурации |
| high / medium / low | P2 / P3 / P4 |

Тип «Вопрос о версиях» в наборе не выделен, поэтому модель его не предлагает; его выбирает клиент или инженер. P1 в наборе нет.

## Как повторить

```sh
python3 -m venv .venv && .venv/bin/pip install scikit-learn ctranslate2 sentencepiece
# CSV — см. DATASET.md; модель перевода — translate-en_ru-1_9.argosmodel (Argos), распаковать zip
.venv/bin/python stage2/ml/translate.py dataset.csv translate-en_ru-1_9 stage2/data.json ru.jsonl
.venv/bin/python stage2/ml/train.py ru.jsonl dataset.csv
```
