# Контракт MCP-инструментов ИИ-ассистента

Ассистент обращается к данным **только** через эти инструменты (allow-list, ИИ-06, P5). Проверка allow-list выполняется на стороне MCP-сервера; вызов вне списка отклоняется и журналируется с `allowed = false`.

| Сервер | Инструмент | Доступ | Вход | Выход | Ограничения |
|---|---|---|---|---|---|
| `tickets` | `tickets.get` | чтение | ticket_number | тема, описание, тип, приоритет, инсталляция, организация (без ПДн автора) | только заявка, по которой готовится предложение |
| `tickets` | `tickets.search_similar` | чтение | ticket_number, limit ≤ 5 | номера и краткие описания похожих закрытых заявок «решено» | только той же организации (ИИ-09) |
| `tickets` | `proposal.save` | запись в одну таблицу | ticket_number, предложение по JSON-схеме `Proposal` | proposal_id | нельзя менять поля заявки; повторный вызов заменяет предложение в статусе `proposed` |
| `kb` | `kb.search` | чтение | запрос, limit ≤ 5 | ID статей, заголовки, фрагменты | только опубликованные статьи |
| `staff` | `staff.get_candidates` | чтение | product, required_level | инженеры, прошедшие детерминированный фильтр компетенций и уровня, их загрузка | ПДн инженеров — только имя |
| `staff` | `staff.get_history_with_org` | чтение | organization_id, engineer_ids | число прошлых заявок организации у каждого инженера | — |

## Чего в allow-list нет (и не может быть добавлено без изменения конституции)

Отправка сообщений клиенту; изменение статуса, приоритета, типа, исполнителя; закрытие заявок; рассылка уведомлений; доступ к серверам клиентов и к учётным данным; доступ к заявкам других организаций.

## Журналирование

Каждый вызов записывается в `AssistantToolCall`: инструмент, аргументы с маскированными ПДн, allowed, хеш результата, задержка, стоимость (FR-027, ИИ-11).
